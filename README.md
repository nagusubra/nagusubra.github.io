# Subu's Site

Personal website and blog built with [Astro](https://astro.build) + Tailwind CSS. Fast, static, and minimal JavaScript — the whole site is server-rendered HTML that ships almost no client-side code.

## Quick start

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
```

## Features

- **Blog** — Markdown/MDX posts, one file per post.
- **Photo dump** — a simple photo gallery.
- **RSS feed** and **sitemap** — generated automatically at build time.
- **Fast by design** — static output, no client-side framework, self-hosted fonts.
